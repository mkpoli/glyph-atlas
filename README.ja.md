# Kuzushiji Atlas

前近代日本語の字形データセット。各レコードは1つの字形出現であり、多くの場合はページ画像上の1文字で、その矩形、翻字者のテキスト、外交的翻刻、変体仮名を含むUnicodeコードポイント、かな字形の字母、漢字の異体字キー、そして資料の製作形態、ジャンル、文体、年代を記録する。データのライセンスはCC BY-SA 4.0で、画像とテキストの権利はレコードごとに記録されるため、利用者は条件に合う部分集合を取ることができる。

素材は、オープンなページ画像に整列されたオープンな翻刻（みんなで翻刻、日本語版Wikisource）と、既存の文字単位データセット（CODH、東京大学史料編纂所、NDL）から来る。既存のデータセットに欠けており本データセットが記録するものは、かな字形ごとの字母とコードポイント、書かれたままの漢字異体字、年代・ジャンル・書体による絞り込みに使える書誌メタデータである。

状態: 計画中。`docs/plan.md`に既存データセットの調査、目標、パイプライン、`docs/schema.md`にデータモデル、`docs/licensing.md`に上流ライセンスの合成方法、`data/sources/`に上流ごとのファイル（ライセンスの根拠と形式）、`docs/implementation/`に作業単位ごとのタスクカードとその依存関係がある。

## レイアウト

- `data/sources/` 上流レジストリ（YAML）、`data/vocab/` 統制語彙。
- `docs/` 計画、スキーマ、ライセンス、決定事項。
- `src/kuzushiji_atlas/` `atlas`コマンド: レジストリ、スキーマモデル、インポータ。
- `tests/` 単体テスト。
- `cache/`、`work/`、`out/` 取得した画像、中間ファイル、リリース。gitには入れない。

## 開発

```sh
uv sync --all-extras --group dev
uv run pytest
uv run atlas sources
```
