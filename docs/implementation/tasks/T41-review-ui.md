# T41 Review interface

Goal: a browser interface for reviewing lines in their page context, fast enough that a reviewer
handles a printed line in well under a minute, and able to produce complete-page truth when the
detector missed lines or characters.

Read first: T40 endpoints, https://github.com/mkpoli/honkoku-client (its `packages/ui` design
tokens and the vertical transcription rendering in `packages/markup`), `docs/implementation/pilot-protocol.md`.

Stack: Svelte 5 with Bun under `apps/review/`, built into `src/kuzushiji_atlas/review/static/` and
served by the T40 server; `devrun bun run dev` in development.

Views
- Page view: the page image with line boxes; click a line to open it; draw a new line where none
  was detected.
- Line view: the line crop, vertical, at readable size; unit boxes drawn; the transcription beside
  it with each character linked to its unit; the neighbouring two lines faint for context; a
  selection model (one unit, or a range of units).
- Actions with keys: accept (a), reject (x), move or resize (drag), split at a point (s), merge the
  selection (m), create a unit for a character with no box (c, then draw), set reading (r), choose
  字母 (j, a list of candidates with their reference glyphs and scores), mark the selection an
  unresolved group (g), note (n), undo (z, undoes the last event of this client through a
  compensating review), next line (space).
- Queue view: the server's queue with progress per document; timing events (`field =
  "timing"`) posted when a line is opened and left.
- Conflict handling: a 409 shows the current state and offers to reapply or discard.

Outputs: the app; `apps/review/README.md`; screenshots in light and dark at desktop and 400 px
widths under `apps/review/shots/`.

Edge cases: a page whose image is not cached (the IIIF URL shown and the page skipped); 割書 lines
with two columns; very long lines (virtualised rendering).

Tests: a Playwright script under `apps/review/tools/` against the T40 server on a fixture dataset:
open a line, split a unit, choose a 字母, undo, and check the posted events; the screenshots
regenerated by the script.

Acceptance: the Playwright script passes; the screenshots reviewed in the pull request.

Size: large. Depends on: T40.
