# 0001 Name and scope

Date: 2026-09-11

## Name

The repository is `kuzushiji-atlas`, Japanese くずし字アトラス. An atlas is a bound set of plates that
locate things; the dataset locates every character on its page and keeps the plates addressable.
The word already names the per-copy character catalogue in a sibling project, so the vocabulary
stays the same across tools.

Names that borrow the みんなで翻刻 brand (みんなでくずし字データセット and the like) were set aside:
a reader would take them for an official product of that platform. Other candidates were 日本字形
コモンズ, くずし字用例集 and 歴史字形アトラス.

## Scope

In: pre-modern Japanese writing on paper, manuscript and printed, 8th to 19th century, with any
character-level annotation that can be tied to an open page image; kana, kanji, marks and ligatures.

Out: modern print (明治 typefaces are covered by NDL and CODH datasets already), 木簡 and 金石文
(different imaging and separate databases), glyph outlines and fonts.
